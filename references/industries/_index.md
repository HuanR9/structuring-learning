# 行业情境叠加索引

行业叠加补充通用岗位路线中缺少的业务流程、系统边界、风险和适用规范；它不替代 `references/domains/` 下的专业模块。

## 路由原则

1. 先按目标岗位或任务建立通用专业路线，再判断行业情境是否会改变学习目标。
2. 只有明确指定行业且存在对应条目时，才加载该行业叠加文件；行业无关的请求不加载。
3. 叠加内容需标清适用行业子类、岗位任务和司法辖区；将通用模块作为基础，不复制完整知识树。
4. 没有匹配条目时，说明当前没有预置行业模块，按用户提供的环境和可核验来源临时裁剪，并记录模块缺口；不要把行业推测写成通用标准。

## 维护边界

- 行业叠加可引用多个专业模块；每次学习仍按岗位任务挑选，不默认把文件中所有内容全部加入路线。
- 法规、行业标准、认证和报告要求可能依国家/地区、产品类别和业务类型而变化，使用前核验最新官方来源。
- 只有相同情境反复出现且需求范围稳定时，才将临时裁剪升级为长期维护的行业模块。
