# 法律类领域模块（legal）

## 领域画像

法律类关注规则的理解、适用与风险控制：从条文到判例，从审查到争议解决。学习主线通常是"懂条文 → 懂实务 → 懂交易/业务 → 懂策略"。

## 通用信源（法律类共享）

- 法条原文优先：法律、行政法规、司法解释原文是第一信源【时效敏感，需核对现行有效版本】。
- 判例验证：裁判文书网、最高法指导案例，理解条文在实务中的真实适用。
- 实践原则：法律类学习结合现行法源与案例；结论注明适用司法辖区、版本和关键事实。先区分概念学习、模拟案例分析与针对真实案件的法律意见；后者超出本 skill 的学习建模范围，不把练习输出包装成正式法律意见。
