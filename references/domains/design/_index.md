# 设计类领域模块（design）

## 领域画像

设计类关注把信息与功能变成可用、好用的体验：从视觉表达到交互逻辑，从单点界面到设计系统。学习主线通常是"懂原则 → 懂工具 → 懂交互 → 懂用户 → 懂体系"。

## 细分路由（L2）

| 触发词 | 细分 | 模块文件 | 状态 |
|---|---|---|---|
| UI、UX、交互、界面设计、体验设计 | UI/UX 设计 | `ui-ux.md` | ✅ 二期 |
| 视觉、平面、品牌、插画 | 视觉设计 | `visual.md` | ✅ 二期 |
| 动效、动画、微交互 | 动效设计 | `motion.md` | ✅ 二期 |
| 设计系统、组件库、设计规范 | 设计系统 | `design-system.md` | ✅ 二期 |

- 命中 🔜 细分：按 `references/core/workflow.md` 通用流程建模，并提示用户可沉淀为该细分模块。
- 用户目标无细分（如"学设计"）：先用本文件给出细分全景，引导用户选一个主攻方向，不要全铺。

## 通用信源（设计类共享）

- 官方规范优先：各平台设计规范（Material Design / Apple HIG / Ant Design 等）【时效敏感，随版本更新】。
- 经典书籍：按细分模块清单取用。
- 实践原则：设计类学习应有可评审产出，但产出形式按细分选择：UI/UX 用界面或流程，视觉用图形/品牌/印刷稿，动效用原型或动效文件，设计系统用组件/规范。不要把完整界面作品强加给不以界面为核心的模块。
