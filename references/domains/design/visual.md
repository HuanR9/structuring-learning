# 视觉设计细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

视觉设计负责品牌与信息的视觉传达：造型、色彩、排版、图形创意到物料落地。核心价值是**"用视觉语言准确传递品牌气质与信息层级"**——视觉的第一功能是让人看懂，其次才是让人觉得美。

## ② 细分路由

本模块即最小细分单位，不再下分。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
视觉设计
├── L1 造型基础
│   ├── 素描与构成（点线面、黑白灰关系，能画准确的形体与明暗）
│   ├── 色彩理论（色立体、色彩心理学、配色套路，能配出和谐商业配色）
│   └── 字体与排版（字体气质、文字层级，能排出信息清晰的海报）
├── L2 数字工具
│   ├── PS/AI 精进（抠图/调色/矢量绘制，能完成商业级精修与图形设计）
│   └── 插画与图形（风格化图形、图标、简单插画创作；能按给定品牌 brief 交付一组风格一致的图标或插画源文件，并用网格和样例检验一致性）
├── L3 品牌层
│   ├── VI 系统（Logo/标准色/标准字/应用规范，能搭一套完整 VI）
│   ├── 品牌调性与情感（视觉如何传递品牌个性；能把品牌关键词转成视觉情绪板和关键画面，并说明每项视觉选择如何对应品牌属性）
│   └── 包装与物料（印刷工艺、材质、刀版图基础；能交付带尺寸、出血、材质和工艺标注的包装稿，并根据印前检查清单修正文件）
└── L4 商业层
    ├── 运营视觉（Banner/活动页/H5 的设计套路与效率；能按一份活动 brief 交付适配目标渠道的素材，并核对信息层级、规格和行动指引）
    └── 动效视觉（基础动态海报、视频包装认知；能完成一段符合品牌风格的动态海报或视频包装，并验证节奏、可读性与导出规格）
```

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1–L2） | 拆解代表性作品并说出决策依据；独立完成一套图标或一组适配具体 brief 的视觉物料 |
| 中级（L3） | 为一个品牌完成 VI 基础系统（Logo+标准色+应用延展）；跟进一次印刷打样并处理工艺问题 |
| 高级（L4） | 主导大型品牌视觉战役；建立可维护的品牌视觉资产库与规范 |

## ⑥ 常见误区

1. **只追风格不懂品牌逻辑**：好看但不传递品牌信息，视觉只是装饰不是资产。
2. **素材拼贴无原创**：依赖素材网站的拼贴稿经不起推敲，原创造型能力是立身之本。
3. **忽视落地规范**：不懂印刷工艺与实现边界，设计稿到实物差之千里。
4. **脱离业务目标**：不问这次设计要达成什么商业目标，作品漂亮但无效。
5. **只看不练眼高手低**：收藏夹存了三千张图不动笔，审美和手上功夫必须同步长。
