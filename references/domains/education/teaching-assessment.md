# 教学与评估细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

教学与评估关注实施学习活动、检查理解、提供反馈并据此调整教学。它包含课堂、工作坊和线上教学中的引导与评价；学习者年龄、学科、文化与制度语境必须进入方案。

## ② 细分路由

本模块聚焦教学现场与学习证据。课程范围、目标和单元结构转 `instructional-design.md`；企业员工发展计划关联人力资源与组织领域。涉及诊断、特殊教育或正式资格评定时遵循当地专业规范。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
教学与评估
├── L1 教学实施基础
│   ├── 教学沟通与示范（解释、例子、思维示范；能针对一个概念设计简明解释和示范，并用提问检查学习者理解）
│   ├── 课堂引导与参与（提问、讨论、协作、课堂规范；能主持一段教学活动并记录参与和理解证据）
│   └── 学习环境与包容性（心理安全、语言差异、可访问性；能为一组学习者调整参与方式并检查是否减少不必要障碍）
├── L2 学习检查与评估
│   ├── 形成性评估（低风险检查、诊断误解、调整教学；能为一个目标设计快速检查并依据模拟结果决定下一步教学）
│   ├── 总结性评估（表现任务、考试、作品集；能设计与学习目标匹配的评估任务并说明评分依据）
│   └── 评分量规与一致性（标准、等级描述、评分偏差；能用量规评价两份样例作品并说明分歧来源和校准方法）
├── L3 反馈与差异化支持
│   ├── 有效反馈（任务/过程/自我调节反馈；能对一个样例作品提供具体、可行动且指向目标的反馈）
│   ├── 误解诊断与补救（错误模式、先备缺口、再教学；能根据学习证据辨认一种误解并设计补救活动）
│   └── 学习支持与公平（差异化、辅助工具、合理调整；能根据学习者需求提出支持方案并检查其公平性和可执行性）
└── L4 评估与持续改进
    ├── 学习数据解释（测量误差、基线、分布与样本限制；能对一组匿名样例数据写出审慎结论并指出不能推断的事项）
    ├── 教学改进循环（计划、实施、观察、反思；能依据一次教学记录提出改进假设和下一轮验证证据）
    └── 评估质量审查（内容效度、可访问性、偏差；能审查一份评估工具并记录至少一项效度或公平性风险）
```

## ④ 权威信源清单

| 级别 | 信源 | 备注 |
|---|---|---|
| 政府证据库 | [What Works Clearinghouse 实践指南](https://ies.ed.gov/ncee/WWC/PracticeGuides) | 含主题化教学建议及证据等级，需核对适用学段与学科 |
| 国际组织 | [UNESCO 学习评估资源](https://www.unesco.org/en/learning-assessments) | 关注评估与课程、教学及学习结果的联系，地区政策不同 |
| 政府标准 | 目标地区课程、考试和教师专业标准 | 用于本地要求与正式评价场景 |
| 研究 | 测量、形成性评估、反馈和公平性研究综述 | 关注测量误差、样本、学科和情境限制 |

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1） | 进行一次示范教学，提交目标检查问题和理解证据 |
| 中级（L2–L3） | 设计并使用一份评估量规，依据结果提供反馈和补救活动 |
| 高级（L4） | 汇总匿名学习证据，完成一轮教学改进并说明结论的适用边界 |

## ⑥ 常见误区

1. **只在课程结束时评估**：过程中的理解检查能更早暴露学习障碍。
2. **把分数当作全部学习证据**：任务设计、评分一致性和测量误差都会影响解释。
3. **反馈只有表扬或纠错**：反馈应指出差距及可执行的下一步。
4. **按单次数据给学习者贴标签**：应结合多种证据、时间变化和背景解释。
5. **忽略评估的公平与可访问性**：无关语言、设备或格式障碍会扭曲目标能力的测量。
