# 产品数据分析细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

产品数据分析用数据发现问题、验证假设、驱动迭代：指标体系、埋点治理、异动归因、实验设计。核心价值是**"把'我觉得'变成'数据说'"**——数据分析师的价值不在取数，而在基于证据的决策支持。

## ② 细分路由

本模块即最小细分单位，不再下分。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
产品数据分析
├── L1 数据基础
│   ├── 指标体系（北极星指标/OSM/AARRR，能为一个产品搭指标树）
│   ├── 埋点设计（事件模型：事件-属性-用户，能设计一次改版的埋点方案）
│   └── SQL 与取数（多表关联/窗口函数/日期函数，能独立完成常规取数）
├── L2 分析方法
│   ├── 漏斗/留存/分群（漏斗定位流失环节、留存曲线判断产品价值）
│   ├── 异动分析与归因（维度拆解、同期群、外部因素排除）
│   └── A/B 实验（假设提出、样本量计算、显著性与陷阱：多重比较/新奇效应）
├── L3 专题分析
│   ├── 用户画像（标签体系与使用边界）
│   ├── 增长分析（渠道质量、LTV/CAC）
│   └── 预测与建模认知（回归/分类的使用场景与解释边界）
└── L4 数据产品与治理
    ├── 报表与看板设计（面向决策 vs 面向监控）
    └── 数据治理认知（指标口径统一、数据质量）
```

## ④ 权威信源清单

| 级别 | 信源 | 备注 |
|---|---|---|
| 书籍 | 《精益数据分析》 | L1–L3 主线，按阶段选指标 |
| 社区 | GrowingIO / 神策数据的方法论文章 | 国内埋点与指标实践 |

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1） | 搭出完整指标树；设计一份埋点方案并通过评审；独立完成常规取数与看板 |
| 中级（L2–L3） | 主导一次核心指标异动归因并给出可执行结论；设计并解读一次 A/B 实验（含样本量与显著性） |
| 高级（L4） | 建立指标口径与治理机制；用数据驱动一次真实的产品决策并被采纳 |

## ⑥ 常见误区

1. **指标堆砌无北极星**：看板几十个指标，没有一个是能指引决策的。
2. **相关当因果**：相关不等于因果，没有实验或准实验设计的结论都是猜测。
3. **A/B 不验样本量**：跑三天就"显著"，p 值操纵比不实验更危险。
4. **埋点混乱无治理**：事件名千人千面，数据可信度为零，分析从建地基开始。
5. **结论自嗨不落地**：分析报告没有指向产品动作，分析就没有完成闭环。
