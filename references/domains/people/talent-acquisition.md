# 招聘与选拔细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

招聘与选拔通过岗位分析、候选人触达和相关能力评估，支持组织在合规、公平和透明的条件下识别人才。流程设计需要考虑岗位、劳动力市场、候选人体验、数据隐私和目标司法辖区要求。

## ② 细分路由

本模块聚焦从岗位需求到录用决策的流程。入职后的绩效、培养和组织能力建设转 `people-development.md`；劳动关系、歧视争议、背景审查合法性等个案事项转法律类并核对适用地区。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
招聘与选拔
├── L1 岗位与人才需求
│   ├── 人力规划与招聘需求（业务计划、岗位空缺、供需假设；能根据模拟业务计划说明招聘需求、优先级和关键假设）
│   ├── 岗位分析与能力标准（任务、责任、能力、工作条件；能为一个岗位写出基于任务的岗位分析和可观察能力标准）
│   └── 招聘渠道与雇主信息（目标人群、渠道覆盖、岗位真实性；能为模拟岗位选择渠道并检查信息是否准确、完整和非歧视）
├── L2 候选人触达与评估
│   ├── 招聘信息与候选人体验（清晰职责、要求、报酬信息、流程；能审阅一则招聘信息并发现模糊、无关或可能排斥候选人的要求）
│   ├── 结构化面试（岗位相关问题、统一流程、评分标准；能为一项能力编写统一问题和行为锚定评分表）
│   └── 工作样本与评估方法（任务代表性、效度、公平、成本；能为岗位能力选择一项评估并说明其效度、公平性与资源限制）
├── L3 决策与录用
│   ├── 证据整合与决策校准（评分、工作样本、参考资料；能用预先设定的标准比较模拟候选人并记录差异处理依据）
│   ├── 录用沟通与谈判（薪酬范围、授权、候选人问题；能为模拟录用沟通准备透明且经过授权的方案与边界）
│   └── 入职交接（承诺、材料、权限、第一阶段目标；能为录用交接建立检查清单并说明哪些信息需要确认）
└── L4 公平与效果改进
    ├── 公平性与偏差审查（岗位相关性、流程差异、群体影响；能对一组匿名评估结果审查不一致并提出需要调查的问题）
    ├── 招聘指标解释（时间、质量、候选人体验、留任；能定义招聘指标并解释其不能独立代表人才质量）
    └── 招聘流程复盘（候选人漏斗、反馈、岗位变化；能基于匿名案例提出一个可验证流程改进并记录保护措施）
```

## ④ 权威信源清单

| 级别 | 信源 | 备注 |
|---|---|---|
| 政府指南 | [美国 OPM 结构化面试指南](https://www.opm.gov/policy-data-oversight/assessment-and-selection/structured-interviews) | 人员评估方法参考；适用美国联邦招聘语境，不是其他地区的法规 |
| 专业框架 | [CIPD Profession Map](https://www.cipd.org/en/the-people-profession/the-profession-map/explore-the-profession-map/core-knowledge/) | 人力资源专业能力框架；注明英国专业组织语境 |
| 地方监管 | 所在司法辖区的人力资源服务、就业、平等机会、个人信息保护和劳动法规 | 招聘要求和限制必须按工作地点核对现行文本 |
| 实践材料 | 经授权脱敏的岗位分析、评分量表、候选人流程数据 | 保护候选人个人信息，不用于真实用人决策的自动推断 |

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1） | 为模拟岗位形成基于任务与能力的岗位分析和招聘需求说明 |
| 中级（L2–L3） | 设计统一面试与评分流程，使用模拟候选人材料完成有依据的决策记录 |
| 高级（L4） | 复盘匿名招聘流程，分析公平性与效果指标并提出可验证的改进方案 |

## ⑥ 常见误区

1. **把学历或年限当能力替代指标**：要求应与岗位任务和必要能力有明确关系。
2. **使用随意面试后凭感觉比较**：不同候选人应基于岗位相关、可比的证据评估。
3. **以招聘指标单独评价质量**：速度、成本和短期留任都需要结合岗位与情境解释。
4. **将自动筛选结果当客观结论**：数据和模型可能复现历史偏差，需要人工审查与申诉机制。
5. **忽视地区法规和隐私要求**：招聘信息、评估与候选人数据处理须按工作地点核实规则。
