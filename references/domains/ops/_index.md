# 运维类领域模块（ops）

## 领域画像

运维类关注系统的稳定运行、交付与治理：从单机到集群，从手工到自动化。学习主线通常是"懂系统 → 懂服务 → 懂架构 → 懂稳定性工程"。

## 细分路由（L2）

| 触发词 | 细分 | 模块文件 | 状态 |
|---|---|---|---|
| DBA、数据库、MySQL、PostgreSQL、Redis、SQL、慢查询、备份恢复 | DBA（数据库运维） | `dba.md` | ✅ 首期 |
| SRE、稳定性、监控、告警、故障应急、oncall | SRE（稳定性工程） | `sre.md` | ✅ 二期 |
| Linux、系统、性能调优、内核、shell | 系统运维 | `system.md` | ✅ 二期 |
| 网络、TCP、DNS、负载均衡、抓包 | 网络运维 | `network.md` | ✅ 二期 |
| K8s、容器、Docker、云原生、CI/CD | 容器与云原生 | `cloud-native.md` | ✅ 二期 |

- 命中 🔜 细分：按 `references/core/workflow.md` 通用流程建模，并提示用户可沉淀为该细分模块。
- 用户目标跨多个细分（如"学运维"无细分）：先用本文件给出细分全景，引导用户选一个主攻方向，不要全铺。

## 通用信源（运维类共享）

- 官方文档优先：各组件官网文档（版本以生产在用版本为准）。
- 经典书籍：按细分模块清单取用。
- 实践原则：运维类学习 [MUST] 包含动手环节，每个模块至少一个可执行的实验（本地 Docker/虚拟机均可），只读不练视为未完成。
