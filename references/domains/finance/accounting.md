# 会计与财务报告细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

会计与财务报告关注经济事项的识别、记录、核对、汇总与披露。基础概念可跨地区学习，但确认和计量规则受适用会计准则、企业类型和报告期间影响；必须在学习材料中标明所用准则。

## ② 细分路由

本模块聚焦会计循环和通用财务报表。管理预算、经营分析与投资项目评估转 `financial-analysis.md`；审计意见、税务申报和真实企业会计政策判断需结合适用规则并由合格专业人士复核。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
会计与财务报告
├── L1 会计概念
│   ├── 会计主体与会计等式（资产、负债、权益；能将样例经济事项映射到账户并检查会计等式是否平衡）
│   ├── 权责发生制与现金制（确认时点、期间配比、现金差异；能比较一个样例交易在两种口径下的期间影响）
│   └── 借贷记账与账户分类（借贷方向、账户性质、余额；能为一组基础交易编制分录并用试算表验证平衡）
├── L2 会计循环
│   ├── 原始凭证与分录（业务事实、凭证、科目、审批轨迹；能根据合成凭证编制分录并解释所需依据）
│   ├── 调整与结账（应计、递延、折旧、结转；能为一个模拟期间编制调整分录并说明对报表的影响）
│   └── 对账与内部控制（银行对账、往来核对、职责分离；能完成一份样例对账并记录差异、责任和处理证据）
├── L3 财务报表
│   ├── 资产负债表（分类、流动性、列报；能从试算表编制简化资产负债表并解释关键分类）
│   ├── 利润表与综合收益（收入、费用、期间业绩；能根据合成交易编制简化利润表并解释权责发生制影响）
│   └── 现金流量表与附注（经营/投资/筹资现金流、重要披露；能把一组样例现金事项分类并指出报表附注的解释作用）
└── L4 准则与报告治理
    ├── 适用准则与政策（IFRS、国家准则、企业类型和报告期间；能为一个模拟报告说明所采用准则、版本和适用范围）
    ├── 估计与判断（确认、计量、减值、重大判断；能识别样例报表中的关键估计并记录所需证据与不确定性）
    └── 财务信息质量（可比性、完整性、重大性、披露；能审查一份样例报表并提出需核实的口径或披露差异）
```

## ④ 权威信源清单

| 级别 | 信源 | 备注 |
|---|---|---|
| 国家准则 | [中国财政部会计准则及解释](https://kjs.mof.gov.cn/zt/kjzzss/qykjzzjs/index.htm) | 中国企业场景；核对适用企业、实施日期和最新解释 |
| 国际准则 | [IFRS Conceptual Framework](https://www.ifrs.org/issued-standards/list-of-standards/conceptual-framework/) 与适用的 IFRS Standards | 不等同于所有国家/地区的法定报告准则 |
| 监管披露 | 目标市场监管机构发布的财务报告规则、公司年报与附注 | 结合报告期间、上市状态和行业要求查阅 |
| 教材 | CFA Institute 财务报告与分析课程资源、基础会计教材 | 用于理解和分析；不代替准则原文或专业意见 |

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1） | 为一组基础交易编制分录、试算并解释会计等式变化 |
| 中级（L2–L3） | 使用合成数据完成一个期间的调整、结账和三大报表勾稽 |
| 高级（L4） | 对指定准则和报告期间审阅样例报表，提交适用范围、关键判断和披露核对记录 |

## ⑥ 常见误区

1. **把借贷方向当作记忆口诀**：先判断账户性质与交易事实，再确认借贷记录。
2. **把利润等同于现金**：权责发生制下收入、费用和现金收付可能跨期。
3. **忽略准则与报告期间**：规则可能因地区、企业类型和生效日期不同。
4. **把账平等同于信息正确**：平衡不证明交易真实、分类恰当或控制有效。
5. **将学习示例用于真实申报**：实际财务报告、审计和税务处理需依适用规则并由专业人员复核。
