# 财务分析与企业财务细分模块

> 领域模块六节 Schema：领域画像 / 细分路由 / 预设知识骨架 / 权威信源清单 / 进阶检查点 / 常见误区。

## ① 领域画像

财务分析与企业财务将财务报表、经营数据和明确假设转化为规划与资源决策信息。主题包括报表分析、预算预测、现金流管理与资本项目评估；分析是决策支持，不保证结果，也不构成面向个人的投资建议。

## ② 细分路由

本模块关注企业或组织的财务决策与分析。基础记账和会计准则转 `accounting.md`；证券估值、投资组合和个人投资目标需另按专业投资教育目标处理；企业融资交易法律关系关联法律类公司与投融资。

## ③ 预设知识骨架

建模（P2）以此树为起点，按用户目标层级裁剪（规则见 `references/core/modeling.md`）。每个叶子节点括注掌握证据。

```
财务分析与企业财务
├── L1 分析基础
│   ├── 分析目的与信息来源（经营、授信、资本预算；能根据一个决策问题列出所需数据、时间范围和主要口径风险）
│   ├── 三大报表关系（利润、资产负债、现金流；能解释一组简化交易如何贯穿三张报表）
│   └── 数据质量与可比性（期间、会计政策、行业差异、一次性项目；能比较两家样例企业并标明不可直接比较的项目）
├── L2 财务表现分析
│   ├── 趋势与结构分析（同比、环比、共同比、业务驱动；能基于一组模拟报表计算趋势并区分事实与解释假设）
│   ├── 盈利与回报指标（利润率、资产回报、资本回报；能计算并解释指标变化的业务驱动和局限）
│   └── 流动性与偿债风险（营运资金、现金转换、杠杆、偿债能力；能使用样例数据识别现金压力信号并提出需补充的证据）
├── L3 规划与资源配置
│   ├── 预算与滚动预测（驱动因素、情景、差异分析；能为模拟部门建立可追溯预算并解释实际差异）
│   ├── 现金流与营运资金（收付款周期、库存、应收应付；能构建简化现金流预测并比较关键假设变化）
│   └── 资本预算（现金流、净现值、回收期、风险；能用合成数据比较项目方案并展示假设敏感性）
└── L4 决策沟通与治理
    ├── 情景与敏感性分析（关键驱动、上下行情景、临界值；能为一个决策模型识别关键变量并计算结果变化区间）
    ├── 管理报告与建议（决策问题、证据、选项、限制；能撰写简短财务建议并区分观测值、假设和判断）
    └── 模型治理（来源、公式检查、版本、审批；能审查一个样例模型并记录公式、来源和使用边界）
```

## ⑤ 进阶检查点

| 阶段 | 能力证据（能做成这些即过关） |
|---|---|
| 初级（L1） | 说明一个分析问题需用的报表、期间、指标和关键限制 |
| 中级（L2–L3） | 基于合成数据完成报表分析、滚动预测和预算差异解释 |
| 高级（L4） | 构建可审查的资本项目或经营决策模型，提交假设、敏感性和模型边界 |

## ⑥ 常见误区

1. **只计算比率不解释驱动**：指标是问题线索，不是因果解释。
2. **忽视会计政策与行业差异**：不同报告口径会影响可比性。
3. **把预测当承诺**：模型结果依赖假设，应展示情景和不确定性。
4. **只给单点估值**：对关键变量进行敏感性分析，说明结果可能如何变化。
5. **把企业分析误作个人投资建议**：本模块支持学习分析方法，不对个人投资作推荐。
